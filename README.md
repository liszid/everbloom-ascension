# Everbloom: Ascension 

Would like to make an rpg game, where you can collect all kinds of materials and use them to craft your own gear and go on dungeon crawling then. Each material has unique feature which will determine the statistics of the gear made, any combination of materials brings forth a gear, which is not predetermined. The more kind and quantity of materials used, the higher the grade of the gear. Based on character actions, he gains skills (if runs a lot, gains movement skill, using sword hives sword mastery, etc.). The goal of the game is to beat the 1000th floor of the dungeon tower. After each floor you return to the village. Each monster drops materials, but you can cultivate a garden, cut trees, mine ores, grab flowers, carve wood, cook food, farm animals etc.
